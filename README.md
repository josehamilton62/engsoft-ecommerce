# 🛒 E-commerce Dropshipping

Bem-vindo ao repositório do **Grupo 3** para a disciplina de Engenharia de Software I. Este projeto documenta a engenharia e modelagem de um sistema web de e-commerce focado no modelo dropshipping para o mercado europeu.

A documentação completa, diagramas UML e a análise do cenário de mudança (manutenção adaptativa) encontram-se no nosso índice principal:

👉 **[Aceder ao Projeto Final Completo Aqui](PROJETO_FINAL.md)**

## 📁 Estrutura do Repositório

O desenvolvimento foi progressivo e dividido em etapas semanais. Abaixo está o resumo do conteúdo de cada diretório:

* **[`semana1/`](semana1/) - Fundamentos do Sistema:** Contém a definição do escopo do projeto, a justificativa da necessidade de engenharia de software e a aplicação dos quatro princípios básicos (modularidade, qualidade, manutenibilidade e boas práticas).
* **[`semana2/`](semana2/) - Requisitos e Viabilidade:** Inclui a dinâmica de elicitação de requisitos com as *personas* (e mediação de conflitos), a lista consolidada de Requisitos Funcionais (RFs) e Não-Funcionais (RNFs), e o Estudo de Viabilidade (técnica, económica e operacional).
* **[`semana3/`](semana3/) - Modelagem UML:** Armazena os ficheiros de modelagem originais (`.drawio`) e exportados (`.png`), englobando o Diagrama de Casos de Uso, Diagrama de Classes e os Diagramas de Sequência individuais ("Checkout" e "Encaminhamento Automático").
* **[`semana4/`](semana4/) - Modelo de Processo:** Documenta a adoção e justificativa do modelo Ágil (framework Scrum) face às características de volatilidade do mercado de dropshipping e da equipa.
* **`PROJETO_FINAL.md`:** O índice unificado do projeto, que inclui a análise detalhada de impacto para o cenário de mudança imposto por fornecedores.
